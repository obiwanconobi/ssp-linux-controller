# Fixtures

The files here are deterministic captures used by the Rust and TypeScript tests.

| File | Contents |
| --- | --- |
| `snapshots/simulator-2.4.4.json` | A full snapshot plus every block editor from the deterministic simulator. It mirrors the firmware-2.4.4 surface: nine blocks, a fixed router, dual NAM/IR groups, four EQ bands, four capture lists, and 52 presets. |
| `snapshots/hardware-2.4.4.json` | A real StompStation PRO capture over USB: 688 nodes, 12 blocks, 14 router slots, 60 presets, five capture lists, real group/tempo metadata, and 0-based EQ bands. |

A live 2.5.3 read-only pass was also made (694 nodes, PNAM switch control
`vtype:["ON","OFF"]`, multi-client Wi-Fi). Its snapshot is not committed
because it contains the user's capture and preset names; the 2.5.3 switch
shape is covered by synthetic tests in `stomp-protocol` and the UI.

The fixture is generated by the CLI against the simulator:

```bash
cargo run -p stomp-sim -- --port 45678
cargo run -p stomp-cli --bin stomp -- fixture tcp:127.0.0.1:45678 \
  fixtures/snapshots/simulator-2.4.4.json
```

The hardware fixture is captured with the same command against
`serial:/dev/ttyACM0`. Do not hand-edit a fixture to make a test pass; add a new
capture and record which firmware and transport produced it.
